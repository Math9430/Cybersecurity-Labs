# Comandi_Base – Introduzione Pratica a Linux

Durante questa attività, svolta all’interno della room “Linux Fundamentals” su TryHackMe, ho applicato una serie di comandi essenziali per orientarmi nel sistema, leggere e modificare file, e comprendere i meccanismi di base dell'interfaccia a riga di comando.

---

## 🛠️ Comandi utilizzati

- `echo` – stampa messaggi nel terminale  
- `whoami` – mostra l’utente corrente  
- `pwd` – indica il percorso della directory attuale  
- `ls` – elenca i file e le cartelle  
- `cd` – consente di cambiare directory  
- `cat` – visualizza il contenuto dei file  
- `grep` – cerca parole o stringhe specifiche nei file  
- `>` e `>>` – scrivono o aggiungono contenuti nei file

---

## 🎯 Obiettivo dell’esercizio

Lo scopo dell’attività era acquisire familiarità con i comandi principali di Linux, imparare a muoversi all’interno del file system e gestire i file in modo efficiente attraverso la riga di comando.
