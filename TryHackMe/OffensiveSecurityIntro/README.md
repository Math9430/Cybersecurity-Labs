# TryHackMe – Offensive Security Intro

## Descrizione
Room su TryHackMe che simula un attacco a una banca per trovare e sfruttare una pagina nascosta. 
Obiettivo: ricognizione e directory brute forcing tramite terminale, trasferimento illecito di fondi fittizi da un conto bersaglio al proprio.

## Obiettivi completati
- [x] Scansione directory nascoste su server remoto
- [x] Uso di wordlist per trovare percorsi sensibili
- [x] Comprensione delle prime fasi di un attacco web
- [x] Eseguire atto malevolo

## Comandi / Strumenti usati

- Gobuster utilizzato per effettuare un attacco di directory brute forcing
- Wordlist: elenco di nomi comuni di cartelle per trovare pagine nascoste
- Terminale Linux per eseguire il tool e navigare nel sistema
